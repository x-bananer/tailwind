## Shade Scale

Tailwind color utilities usually use a color name plus a shade number:

| Pattern | Example |
| --- | --- |
| `color-100` | `red-100` |
| `color-200` | `green-200` |
| `color-300` | `emerald-300` |
| `color-400` | `zinc-400` |
| `color-500` | `slate-500` |
| `color-600` | `orange-600` |
| `color-700` | `fuchsia-700` |
| `color-800` | `pink-800` |

Lower numbers are lighter. Higher numbers are darker.

## Common Color Utilities

| Utility type | Example |
| --- | --- |
| Text color | `text-red-100` |
| Background color | `bg-emerald-300` |
| Border color | `border-blue-400` |
| Divide color | `divide-fuchsia-300` |
| Outline color | `outline-red-500` |
| Accent color | `accent-purple-500` |
| Shadow color | `shadow-purple-500/50` |

## Arbitrary Colors

You can also use custom values directly:

- `bg-[#427fab]`
- `bg-[rgb(255, 0, 0)]`
- `bg-[deeppink]`
